# Calculator

A responsive glassmorphism calculator built with plain HTML, CSS and JavaScript (no dependencies).

## Features

- **Basic & Scientific modes** – sin, cos, tan, ln, log, √, xʸ, n!, π, e, |x|
- **DEG / RAD** toggle for trigonometry
- **Safe parser** – expressions are evaluated by a custom parser, not `eval`
- **Live preview** of the result while typing, brackets auto-close, implicit multiplication (`2π`, `3(4+1)`)
- **Memory** keys (MC, MR, M+, M−) and `Ans` for the previous result
- **History** (last 30, saved in localStorage) – click to reuse a result, Shift+click to reuse the expression
- **Copy** result to clipboard
- **Dark / light theme**, remembered between visits
- **Keyboard support** – digits, `+ - * / ^ % ! ( )`, `Enter`, `Backspace`, `Esc`, `p` for π
- Mobile friendly (history becomes a slide-in drawer)

Open `index.html` in a browser to use it.
